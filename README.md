GPS navigation using Dijkstra’s algorithm

Develop a simple GPS navigation system to find optimal routes between towns and villages in Belgium
Use a prepared road network, containing road intersections, connections, distances, and estimated travel times stored (as a dictionary) in a JSON file
Read data from a JSON file and construct a weighted graph
Implement Dijkstra’s algorithm to find the shortest route between two selected locations
Display the road network and highlight the calculated routes using Matplotlib
Extend the algorithm to find the fastest route by considering different road types and speed limits

Optional:

Optimise Dijkstra’s algorithm using Python’s heapq library and compare its performance with the original implementation
